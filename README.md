# MediaPlugin

פלאגין Spigot/Paper שנותן ליוטיוברים/סטרימרים בשרת שלך פאנל `/media` עם 10 כפתורים,
כולל ניהול הרשאות פנימי (בלי צורך בפלאגין הרשאות חיצוני).

## מה יש בפאנל (/media)

1. **אני בלייב** - מכריז לכל השרת שהיוטיובר עלה/ירד משידור חי (כולל קישור אם הוגדר)
2. **הודעת הגרלה** - פותח קלט בצ'אט ומשדר הודעת הגרלה מעוצבת לכל השרת
3. **וניש** - הופך את השחקן לבלתי נראה
4. **טיסה** - הפעלת/כיבוי מצב טיסה
5. **מילוי חיים ורעב** - החלמה מיידית מלאה
6. **ניקוי מזג אוויר** - עוצר גשם/סערה
7. **קביעת זמן ליום** - לתאורה טובה בהקלטות
8. **אלמוות** - מצב חסין נזק (ללא מוות בשידור)
9. **שידור הודעה כללית** - הודעה מעוצבת לכל השרת
10. **מצב הקלטה** - מנקה צ'אט ומסתיר הודעות כניסה/יציאה בזמן הקלטה

כל כפתור מוצג רק אם לשחקן יש גישה אליו. שחקן ללא גישה בכלל רואה פריט אפור.

## ניהול יוטיוברים (בלי פלאגין הרשאות)

הפלאגין מנהל בעצמו רשימת "יוטיוברים" הנשמרת בקובץ `players.yml`:

```
/media add <שם_שחקן>     - נותן לשחקן גישה מלאה לכל הפאנל
/media remove <שם_שחקן>  - מסיר גישה
/media list               - מציג את כל היוטיוברים המורשים
/media setlink <קישור>    - כל יוטיובר מגדיר את קישור השידור שלו
```

שחקן שנוסף עם `/media add` מקבל אוטומטית גישה לכל הפיצ'רים - לא צריך LuckPerms
או כל פלאגין הרשאות אחר. אם אתה כן משתמש בפלאגין הרשאות, אפשר גם לתת
node-ים ספציפיים (`media.live`, `media.giveaway` וכו', ראה `plugin.yml`)
לשליטה עדינה יותר בלי להשתמש ב-`/media add`.

## בנייה (Build)

הפרויקט הוא פרויקט Maven רגיל. כדי לבנות אותו לקובץ jar:

1. ודא שמותקן אצלך **Java 17+** ו-**Maven**.
2. מתוך תיקיית הפרויקט, הרץ:
   ```
   mvn clean package
   ```
3. קובץ ה-jar המוכן יימצא ב: `target/MediaPlugin.jar`

> שימו לב: הסביבה שבה אני כותב את הקוד אין לה גישה לאינטרנט, ולכן אני לא יכול
> להוריד את ספריית Spigot API ולקמפל את הקובץ בעצמי כאן. ה-build עצמו פשוט -
> `mvn clean package` יעשה את כל העבודה אצלך תוך שניות (Maven מוריד את
> Spigot API אוטומטית מה-repo הציבורי שמוגדר ב-pom.xml).

אם אין לך Maven מותקן ולא בא לך להתעסק - יש גם אתרים כמו
[Spigot BuildTools](https://www.spigotmc.org/wiki/buildtools/) שיכולים לעזור,
אבל הכי פשוט זה פשוט להתקין Maven (`apt install maven` / `brew install maven` וכו').

## התקנה

1. שים את `MediaPlugin.jar` בתיקיית `plugins/` של השרת.
2. הפעל מחדש (או `/reload` אם אתה משתמש בזה, לא מומלץ).
3. תן לעצמך/לאדמינים הרשאת `media.admin` (או פשוט הרץ בתור OP).
4. הרץ `/media add <שם_יוטיובר>` לכל יוטיובר שרוצים לתת לו גישה.
5. היוטיובר מריץ `/media` ורואה את הפאנל.

## התאמה אישית

כל הטקסטים וההודעות נמצאים ב-`config.yml` בתיקיית הפלאגין אחרי הריצה
הראשונה - אפשר לערוך צבעים, ניסוחים והודעות בלי לגעת בקוד.
